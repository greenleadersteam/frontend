# Документация веб-клиента «Московские посадки»

Команда Green Leaders.

Веб-клиент сервиса автоматического проектирования озеленения: загрузка подосновы, просмотр и проверка плана посадок, правки, выгрузки и геопривязка чертежа.

| Раздел                                     | Содержание                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------- |
| [Назначение и границы](scope.md)           | Что входит в версию, что — на развитие, режимы «Сервер» и «Демо», возможности сервера |
| [Архитектура](architecture.md)             | Слои и модули, потоки данных, развёртывание                                           |
| [Интерпретируемость](interpretability.md)  | Как у каждой посадки появляется объяснение: нормы, расстояния, пункты актов           |
| [Правки и выгрузки](editing-and-export.md) | Правка расстановки, статусы, слой DXF, ведомости, отчёт для согласования              |
| [Геопривязка](georeference.md)             | Модуль совмещения чертежа с картой, оценка точности, привязка проекта                 |
| [Методы и библиотеки](libraries.md)        | Зависимости, их лицензии, данные карты и нормативные акты                             |
| [Ограничения](limitations.md)              | Допущения, известные ошибки, что зависит от сервера                                   |
| [Работа с интерфейсом](ui-guide.md)        | Экраны по порядку сценария, со снимками                                               |

Запуск и проверка — в [README.md](../README.md) в корне репозитория.

Схемы написаны на Mermaid; рядом с каждой лежит PNG в [images/](images/) для печати.
