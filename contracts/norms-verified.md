# Нормы отступов: сверка с первоисточниками

Задача для бэкенда: сопоставить каждую норму из `greenplan/norms/default.yaml` с пунктом нормативного акта. Здесь — результат сверки фронтенда. Демо показывает жюри пункт только из этой таблицы и только там, где значение сервиса совпадает с первоисточником.

Проверено 27.09.2026. Значения — «дерево / кустарник», метры, минимальное расстояние до оси растения. Прочерк «–» в первоисточнике значит «не нормируется», а не «как у дерева».

## Замечания для бэкенда

1. **Бортовой камень.** Сервис применяет к бортовому камню строку «край тротуара» (0,7 / 0,5). Если борт отделяет проезжую часть, действует строка «край проезжей части» (2,0 / 1,0); уменьшить отступ можно только по примечаниям 4, 5, 7 к табл. 9.1 СП 42 (корневые барьеры). С отступом 2,0 правило `TREE_ROW_CURB` (offset 2,2) проходит, `SHRUB_HEDGE_CURB` (offset 0,8) — нет.
2. **Существующее дерево.** Таблица 3.6.2 — ориентировочный шаг посадки деревьев на магистралях, а не отступ от существующего дерева. Использовать её так — интерпретация сервиса. Кустарниковое 1,5 м первоисточником не подтверждено.
3. **Прочерк у кустарника** значит «норма не установлена». Показывать пункт рядом с кустарниковыми 1,5 или 2,0 м нельзя: это консервативное значение сервиса.
4. **Способ измерения.** По примечанию 5 к табл. 9.1 СП 42 (изм. № 2) расстояние до сетей измеряется между наружными поверхностями ствола и трубы, хотя шапка таблицы говорит «до оси ствола». Сервис считает от линии сети до точки ствола — стоит сверить.
5. **Какой акт показывать.** Таблица 3.6.1 в 743-ПП помечена как взятая из МГСН 1.01-99; равнозначная федеральная ссылка — СП 42.13330.2016, п. 9.6, табл. 9.1.
6. **Источник сервиса** «Правила размещения растений в городской среде.xlsx» не проверен: его нет в репозитории бэкенда.
